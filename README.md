# Bible Reader content — ZH-Chinese

This repository contains the Bible Reader SD-card content for **ZH-Chinese**.

## Directory layout

- `text/ZH-Chinese/` — all Bible translations and their original nested folder structure.
- `audio/ZH-Chinese/` — audio Bible book folders and chapter MP3s.
- `gospel/ZH-Chinese/` — Gospel files, retaining original names such as `Gospel.txt` and `Gospel.mp3`.

Copy these folders into the root of the Bible Reader `SDCARD` staging directory.
Do not rename files or flatten directories: the firmware expects the original paths.
